# Extended Key Signatures (Grade 2)

## What you will learn

- Four new key signatures: D major (2#), A major (3#), Bb major (2b), Eb major (3b)
- How to identify major keys from their key signatures
- How to find the relative minor for each key signature

## AMEB Syllabus Reference

> **AMEB Piano 2026 · Grade 2 · Section III**
> Candidates must be able to identify key signatures of up to **3 sharps** and **3 flats**, name the corresponding major key and its relative minor.

## Recap: The Rules for Identifying Keys

**Sharp keys:** Look at the last (rightmost) sharp. The major key is **one semitone higher** than that sharp.
- Last sharp = F# → key is G major
- Last sharp = C# → key is D major
- Last sharp = G# → key is A major

**Flat keys:** Look at the second-to-last flat. That flat *names* the major key.
- Second-to-last flat = Bb → key is Bb major
- Second-to-last flat = Eb → key is Eb major
- Special case: 1 flat (Bb) → F major (memorise)

## The Four New Key Signatures

### D Major — 2 Sharps: F# C#

```abc
X:1
T:D major key signature — 2 sharps
L:1/4
K:D
d4 |]
```

Last sharp = C#. One semitone above C# = D. ✓ Key = **D major**.
Relative minor: A minor (6th degree of D major scale: D E F# G **A** B C# D → A minor).

### A Major — 3 Sharps: F# C# G#

```abc
X:1
T:A major key signature — 3 sharps
L:1/4
K:A
a4 |]
```

Last sharp = G#. One semitone above G# = A. ✓ Key = **A major**.
Relative minor: F# minor.

### Bb Major — 2 Flats: Bb Eb

```abc
X:1
T:Bb major key signature — 2 flats
L:1/4
K:Bb
_b4 |]
```

Second-to-last flat = Bb. ✓ Key = **Bb major**.
Relative minor: G minor (count down 3 semitones from Bb: Bb → A → Ab → G → G minor).

### Eb Major — 3 Flats: Bb Eb Ab

```abc
X:1
T:Eb major key signature — 3 flats
L:1/4
K:Eb
_e4 |]
```

Second-to-last flat = Eb. ✓ Key = **Eb major**.
Relative minor: C minor.

| A major | 3# (F#, C#, G#) | F# minor |
| F major | 1b (Bb) | D minor |
| Bb major | 2b (Bb, Eb) | G minor |
| Eb major | 3b (Bb, Eb, Ab) | C minor |

## Finding the Relative Minor

The relative minor always starts **3 semitones below** the major tonic (or equivalently, on the 6th degree of the major scale).

A quick formula:
1. Name the major tonic
2. Count down 3 semitones (or up 9): that is the relative minor tonic
3. The relative minor uses the same key signature

| Major | Count down 3 semitones | Relative minor |
|---|---|---|
| D | D → C# → C → B | B minor |
| A | A → G# → G → F# | F# minor |
| Bb | Bb → A → Ab → G | G minor |
| Eb | Eb → D → Db → C | C minor |

> **Teaching tip:** Many students find relative minors confusing because they expect a consistent jump. Emphasise that 3 semitones down is always the rule — and that both the major and its relative minor share *exactly* the same sharps and flats. Show this on a keyboard: Bb and G are 3 semitones apart, and a piece in G minor uses the same key signature (2 flats) as Bb major.

## The Reverse Question: Key Signature → Relative Minor

The exam may ask: "What is the relative minor of Eb major?"
- Count 3 semitones below Eb: Eb → D → Db → C → **C minor**

Or: "What major key has the same key signature as C minor?"
- C minor → count 3 semitones *up* from C: C → Db → D → Eb → **Eb major**

## How the examiner tests this

- "Name the major key with this key signature." (Show 2 sharps → "D major")
- "What is the relative minor of A major?" → "F# minor"
- "Write the key signature of Bb major on the treble clef."
- "Name all the accidentals in the key of Eb major." → "Bb, Eb, Ab"
- "What key has 3 sharps?" → "A major"

## Common mistakes

- **Forgetting to look at the second-to-last flat** for flat key signatures (and just naming the last flat as the key).
- **Confusing relative minor with parallel minor.** The relative minor of D major is B minor (different tonic, same key sig). The parallel minor of D major is D minor (same tonic, different key sig). These are very different things.
- **Getting the direction wrong for relative minor.** Always count 3 semitones *below* the major tonic, not above.
- **Mixing up B minor and Bb minor** as the relative of D major. D → C# → C → B → it is **B minor** (not Bb minor — that would be 4 semitones down).

## Key points

- **D major**: 2 sharps (F#, C#). Relative minor: **B minor**.
- **A major**: 3 sharps (F#, C#, G#). Relative minor: **F# minor**.
- **Bb major**: 2 flats (Bb, Eb). Relative minor: **G minor**.
- **Eb major**: 3 flats (Bb, Eb, Ab). Relative minor: **C minor**.
- Relative minor = 3 semitones below the major tonic; shares the same key signature.
- Sharp rule: last sharp + 1 semitone = major key. Flat rule: second-to-last flat = major key.
