# Chord Inversions (Grade 3)

## What you will learn

- What a chord inversion is
- Root position vs first inversion — how to tell them apart
- First inversions of all six Grade 3 chords

## AMEB Syllabus Reference

> **AMEB Piano 2026 · Grade 3 · Section III**
> Candidates must be able to identify **first inversion** triads (written or played) of the following chords: **C major, G major, F major, A minor, D minor, E minor**. They must be able to distinguish root position from first inversion.

## What Is an Inversion?

In **root position**, the chord's name note (the root) is at the bottom: C–E–G (C major, root position).

When we **rearrange** the notes so a different note is at the bottom, we create an **inversion**. The notes of the chord remain the same — only the order changes.

- **Root position**: Root at the bottom (R–3rd–5th)
- **First inversion**: 3rd at the bottom (3rd–5th–R)
- **Second inversion**: 5th at the bottom (5th–R–3rd) — not tested at Grade 3, but good to know

> **Teaching tip:** Show the student how a chord in first inversion sounds on the piano compared to root position. The notes are identical but the "colour" is slightly different. First inversion has a less stable, more flowing character — composers use it for passing chords between stronger root-position chords.

## Building First Inversions

To convert root position to first inversion: **take the bottom note and move it an octave higher**.

**C major root position**: C–E–G → move C up an octave → **E–G–C** (first inversion)

The result always has the 3rd at the bottom.

## The Six Grade 3 First Inversion Chords

### C Major First Inversion — E G C

Root position: C E G → move C to top → **E G C**

```abc
X:1
T:C major — root position then first inversion
M:4/4
L:2
K:C
[ceg][egc'] |]
```

The first inversion (E–G–C) is sometimes called "C major 6/3" in figured bass notation, where 6 and 3 refer to the intervals above the bass note.

## Summary Table

| Chord | Root position | First inversion |
|---|---|---|
| C major | C E G | **E** G C |
| G major | G B D | **B** D G |
| F major | F A C | **A** C F |
| A minor | A C E | **C** E A |
| D minor | D F A | **F** A D |
| E minor | E G B | **G** B E |

In every first inversion, the **3rd of the chord is at the bottom**.

## Identifying Root Position vs First Inversion

When shown a chord, determine its position:

1. **Name all three notes** of the chord.
2. **Identify the chord name** (which major or minor triad uses these three notes?).
3. **Check the bottom note**:
   - If the bottom note = the root (chord name note) → **root position**
   - If the bottom note = the 3rd of that chord → **first inversion**

**Example**: Notes shown: G B D. What chord and what position?
- G B D = G major chord.
- Bottom note = G = root of G major → **G major, root position**.

**Example**: Notes shown: B D G. What chord and what position?
- B D G = G major chord (G is just at the top).
- Bottom note = B = the 3rd of G major → **G major, first inversion**.

## How the examiner tests this

- "Is this chord in root position or first inversion?" → Show chord on staff → answer.
- "Write C major in first inversion on the treble clef."
- "Name this chord and state its position." → Show E–G–C → "C major, first inversion."
- "What note is at the bottom of a first inversion chord?" → "The 3rd of the chord."
- "How do you turn a root position chord into first inversion?" → "Move the root (bottom note) up an octave."

## Common mistakes

- **Naming only the notes, not the position.** Always state both: "D minor, first inversion" — not just "D minor."
- **Confusing first inversion with a different chord.** E–G–C is not an "E minor" chord — it is C major in first inversion. Identify all three notes, find the triad they belong to, then state the position.
- **Forgetting which note is at the bottom in first inversion.** It is always the **3rd** of the chord. Memorise: "First inversion = 3rd at the bottom."

## Key points

- **Root position**: root note is at the bottom.
- **First inversion**: 3rd of the chord is at the bottom (root moved up an octave).
- Method: name the three notes → identify the chord → check if bottom note is root (root position) or 3rd (first inversion).
- Grade 3 first inversion chords: **C major (E G C), G major (B D G), F major (A C F), A minor (C E A), D minor (F A D), E minor (G B E)**.
