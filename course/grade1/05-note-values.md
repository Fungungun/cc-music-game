# Note Values and Rests

## What you will learn

- The names and shapes of the five note values used in Grade 1
- How many beats each note lasts
- The rest that corresponds to each note
- How note values relate to each other

## AMEB Syllabus Reference

> **AMEB Piano 2026 · Grade 1 · Section III**
> Candidates must be able to name each note and rest symbol (semibreve through semiquaver) and state its value in crotchet beats. They may be asked to draw a note of a specified value on a blank staff.

## The Note Family

Notes are named by how long they last. In 4/4 time (four beats per bar), the relationships are:

| Name (UK) | Name (US) | Symbol | Beats in 4/4 |
|---|---|---|---|
| Semibreve | Whole note | open oval, no stem | 4 |
| Minim | Half note | open oval with stem | 2 |
| Crotchet | Quarter note | filled oval with stem | 1 |
| Quaver | Eighth note | filled oval, stem + 1 flag | ½ |
| Semiquaver | Sixteenth note | filled oval, stem + 2 flags | ¼ |

> **Teaching tip:** The AMEB exam uses UK terminology (semibreve, minim, crotchet, quaver, semiquaver). Make sure your student knows both the UK name and the beat value. The US names are useful as a hint — "whole" and "half" suggest the relationship.

Each note is exactly half the value of the one above it:

```
Semibreve (4) = 2 Minims = 4 Crotchets = 8 Quavers = 16 Semiquavers
```

```abc
X:1
T:Semibreve, minim, two crotchets, four quavers (all = 4 beats)
L:1/4
K:C
c4 | c2 c2 | c c c c | cccc cccc |]
```

## Rests

Every note value has a matching **rest** — a period of silence lasting the same number of beats.

| Note | Rest | Beats |
|---|---|---|
| Semibreve | Semibreve rest (rectangle hanging below line 4) | 4 |
| Minim | Minim rest (rectangle sitting on top of line 3) | 2 |
| Crotchet | Crotchet rest (zig-zag shape) | 1 |
| Quaver | Quaver rest (7-like shape) | ½ |
| Semiquaver | Semiquaver rest (7 with two hooks) | ¼ |

A helpful memory trick: the semibreve rest **hangs** below the line (it is heavy, like a full note), while the minim rest **sits** on top of the line (it is lighter — half as heavy).

```abc
X:1
T:Semibreve and minim rests
L:1/4
K:C
z4 | z2 z2 |]
```

## Counting Beats

To count how many beats a note gets, think of the crotchet as the "1 beat" unit. Everything else is relative:

- Semibreve: count 1-2-3-4 (hold for four beats)
- Minim: count 1-2 (hold for two beats)
- Crotchet: count 1
- Quaver: count 1-and (two quavers fit in one crotchet beat)
- Semiquaver: count 1-e-and-a (four semiquavers fit in one crotchet beat)

> **Teaching tip:** Clap the note values while saying the counts aloud. First clap a steady crotchet pulse (1, 2, 3, 4, 1, 2, 3, 4...). Then clap a semibreve on beat 1 and show that it lasts until beat 1 of the next bar. This physical exercise is also part of the AMEB aural test.

## Adding Up Note Values

A common exam question asks you to state how many beats a note is worth *in a given time signature*. The answer is always the same for semibreve–semiquaver (these values do not change with the time signature) unless the time signature uses a different unit note (e.g., 6/8 uses quavers, but that is Grade 2).

**Example**: How many crotchet beats does a minim last? **2 beats.**

**Example**: How many quavers fit into a minim? **4 quavers.**

## How the examiner tests this

The examiner will show you a note or rest and ask:
- "Name this note/rest."
- "How many beats does this note last?" (always specify: "in 4/4 time" or similar)
- "How many [smaller notes] fit into a [larger note]?" e.g., "How many crotchets equal a semibreve?"

They may also ask you to draw a note or rest of a given value on a blank staff.

## Common mistakes

- **Confusing minim and semibreve rests.** The semibreve rest hangs *down* from a line; the minim rest sits *on top* of a line. They look similar — remember "heavy hangs, light sits."
- **Saying a minim is worth 4 beats.** It is worth 2. The semibreve is worth 4.
- **Forgetting the flags on quavers and semiquavers.** A crotchet with a flag becomes a quaver. Two flags = semiquaver.
- **Claiming notes change value between time signatures.** A semibreve always equals two minims; a crotchet always equals two quavers. The number of beats in a bar changes, but the relationships between note values do not.

## Key points

- **Semibreve** = 4 beats; **Minim** = 2; **Crotchet** = 1; **Quaver** = ½; **Semiquaver** = ¼
- Each note value is exactly half of the one above it.
- Every note has a matching rest with the same duration.
- Semibreve rest hangs below a line; minim rest sits on top of a line.
- Use UK note names for the AMEB exam.
