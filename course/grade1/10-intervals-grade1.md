# Intervals (Grade 1)

## What you will learn

- What an interval is
- How to count intervals correctly
- The six intervals tested at Grade 1: unison, 2nd, 3rd, 4th, 5th and octave
- Harmonic and melodic intervals

## AMEB Syllabus Reference

> **AMEB Piano 2026 · Grade 1 · Section III**
> Candidates must be able to name any interval from **unison to octave** above a given note using the number only: "a 3rd", "a 5th", etc. Both harmonic (notes together) and melodic (notes in sequence) intervals may be shown. Quality names (major, minor, perfect) are not required at Grade 1.

## What Is an Interval?

An **interval** is the distance in pitch between two notes. Intervals are at the heart of music: melodies move through intervals, and chords are built by stacking them.

Intervals have two properties:
1. **Number** — how many letter names are spanned (always including both notes)
2. **Quality** — whether the interval is major, minor, perfect, etc. (Grade 2 onwards)

At Grade 1, you only need to identify the **number**.

## How to Count an Interval

Count every letter name from the lower note to the upper note, **including both the note you start on and the note you finish on**.

**Example:** C to G
C (1) → D (2) → E (3) → F (4) → G (5) = a **5th**

**Example:** C to E
C (1) → D (2) → E (3) = a **3rd**

The count always includes both the starting note and the finishing note. This is the most important rule.

> **Teaching tip:** Use your fingers to count. Place your thumb on the lower note name and count up to the upper note. The finger number you land on is the interval number. C=thumb(1), D=index(2), E=middle(3) → 3rd. This physical counting prevents errors.

## The Six Grade 1 Intervals

| Interval | Example | Count |
|---|---|---|
| Unison (1st) | C to C | 1 (same note) |
| 2nd | C to D | C D = 2 |
| 3rd | C to E | C D E = 3 |
| 4th | C to F | C D E F = 4 |
| 5th | C to G | C D E F G = 5 |
| Octave (8th) | C to C (higher) | C D E F G A B C = 8 |


*(The notation above shows harmonic intervals — both notes sounded together.)*

## Harmonic and Melodic Intervals

- **Harmonic interval**: both notes sounded at the same time (written one above the other on the staff).
- **Melodic interval**: notes sounded one after the other (written left to right on the staff).

```abc
X:1
T:Melodic intervals — C up to each note in turn
L:1/4
K:C
c d | c e | c f | c g | c c' |]
```

The method for counting is identical for both types.

## Intervals From Any Note

The exam will test intervals from different starting notes, not just C. The counting method always works: start on the lower note, count letter names upwards.

**Example:** G to D
G (1) → A (2) → B (3) → C (4) → D (5) = a **5th**

**Example:** F to A
F (1) → G (2) → A (3) = a **3rd**

**Example:** A to E
A (1) → B (2) → C (3) → D (4) → E (5) = a **5th**

Note: sharps and flats do **not** change the interval number — they affect the quality (Grade 2). F to A and F to Ab are both 3rds.

## Common Intervals in Music

Intervals are used everywhere in music. Some easily recognisable examples:

| Interval | Familiar melody beginning |
|---|---|
| Unison | Same note repeated |
| 2nd | "Happy Birthday" (Hap-py) |
| 3rd | "Kookaburra sits in the old gum tree" (first two notes) |
| 4th | "Here Comes the Bride" (Here comes) |
| 5th | "Star Wars theme" (opening two notes) |
| Octave | "Somewhere Over the Rainbow" (Some-where) |

## How the examiner tests this

At Grade 1, the examiner will:
- Show two notes on the staff (harmonic or melodic) and ask: "Name this interval." → Answer: "A 3rd" / "A 5th" etc.
- Ask you to mark an interval above or below a given note: "Write a note a 4th above this G."
- Ask: "How do you count an interval?" → Explain including both notes.

Note: At Grade 1, you only need to say the **number** (e.g., "a 5th"). You do not need to say "perfect 5th" or "major 3rd" — that is Grade 2.

## Common mistakes

- **Not including both notes in the count.** C to G = 5th, not 4th. Always include the starting note as 1.
- **Confusing interval number with number of semitones.** A 3rd from C can be C-E (4 semitones) or C-Eb (3 semitones) — but both are still called a 3rd. The *number* only counts letter names.
- **Forgetting that sharps/flats don't change the number.** C to F# is still a 4th. The sharp changes the quality (Grade 2), not the number.
- **Counting only the notes in between.** "C D E" — some students count only D and E (2 notes in between), giving 2 instead of 3. Always count all letter names including both endpoints.

## Key points

- An **interval** is the distance between two notes.
- Count every letter name from lower to upper note, **including both**.
- Grade 1 intervals: **unison, 2nd, 3rd, 4th, 5th, octave (8th)**.
- Sharps and flats do not change the interval number — only the quality (Grade 2).
- **Harmonic**: both notes together; **Melodic**: notes one after the other. Counting is the same for both.
